# 家計簿アプリ (KakeiboApp)

SwiftUIで作成したシンプルで使いやすい家計簿アプリです。

## 📱 機能

### 主な機能
- **収支管理**: 収入と支出を簡単に記録
- **カテゴリ分類**: 食費、交通費、娯楽など多様なカテゴリで分類
- **統計表示**: 今月の収支をグラフで視覚化
- **取引履歴**: 過去の取引を日付別に表示
- **データ永続化**: UserDefaultsを使用してデータを保存

### 画面構成
1. **ホーム画面**
   - 現在の残高表示
   - 今月の収入・支出サマリー
   - 最近の取引一覧

2. **統計画面**
   - 今月の収支サマリー
   - カテゴリ別支出の円グラフ
   - カテゴリ別支出の詳細リスト

3. **履歴画面**
   - 全取引の一覧表示
   - 収入/支出でフィルタリング
   - スワイプで削除機能

4. **取引追加画面**
   - 収入/支出の選択
   - カテゴリ選択
   - 金額入力
   - 日付選択
   - メモ入力

## 🚀 セットアップ

### 必要要件
- Xcode 15.0以上
- iOS 17.0以上のシミュレータまたは実機

### インストール手順

1. プロジェクトをクローンまたはダウンロード
```bash
cd KakeiboApp
```

2. Xcodeでプロジェクトを開く
```bash
open KakeiboApp.xcodeproj
```

3. シミュレータまたは実機を選択

4. ⌘ + R でビルド＆実行

## 💡 使い方

### 取引を追加する
1. ホーム画面または履歴画面の右上の「+」ボタンをタップ
2. 収入または支出を選択
3. カテゴリを選択
4. 金額を入力
5. 必要に応じて日付とメモを入力
6. 「保存」をタップ

### 統計を確認する
1. 下部タブバーの「統計」をタップ
2. 今月の収支サマリーを確認
3. カテゴリ別の支出割合を円グラフで確認
4. 各カテゴリの詳細を確認

### 取引を削除する
1. 履歴画面を開く
2. 削除したい取引を左にスワイプ
3. 「削除」をタップ
